# 🚀 Python Practice Programs: Loops and Conditionals

This repository contains 10 beginner-friendly Python programs that focus on using **conditional statements** and **loops**. These are useful for students, beginners, and anyone practicing Python fundamentals.

---

## 📂 Program List

### 🔁 Loops Based

1. **Print 1 to N Natural Numbers**  
   📄 [`program_1.py`](program_1.py)  
   ➤ Uses `for` loop to print numbers from 1 to N.

2. **Sum of Digits of a Number**  
   📄 [`program_2.py`](program_2.py)  
   ➤ Uses `while` loop to extract and sum digits.

3. **Factorial of a Number**  
   📄 [`program_3.py`](program_3.py)  
   ➤ Uses `for` loop and conditionals to calculate factorial.

4. **Multiplication Table**  
   📄 [`program_4.py`](program_4.py)  
   ➤ Generates table using `for` loop.

5. **Fibonacci Series**  
   📄 [`program_5.py`](program_5.py)  
   ➤ Uses `while` loop to print first `n` Fibonacci numbers.

---

### 🔀 Conditional Statements Based

6. **Check Even or Odd**  
   📄 [`program_6.py`](program_6.py)  
   ➤ Simple `if-else` check.

7. **Find Maximum of Three Numbers**  
   📄 [`program_7.py`](program_7.py)  
   ➤ Compares three numbers using nested conditions.

8. **Leap Year Checker**  
   📄 [`program_8.py`](program_8.py)  
   ➤ Uses logical conditions to determine leap year.

9. **Grade System**  
   📄 [`program_9.py`](program_9.py)  
   ➤ Maps marks to grades using `if-elif-else`.

10. **Positive, Negative, or Zero**  
   📄 [`program_10.py`](program_10.py)  
   ➤ Categorizes a number with conditional checks.
